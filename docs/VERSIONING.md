# Versioning and document control

**Document version:** 1.0.0

**Level:** Controlled

**Last reviewed:** 2026-09-29

The Job Portal uses semantic versions for application releases. Major versions change workflows or data structures, minor versions add backward-compatible capabilities, and patch versions contain backward-compatible fixes.

Candidate-owned documents use independent integer revisions. Replacing a source resume increments its revision. Each tailored resume and cover letter carries the revision used for that application so the submitted artifact remains auditable.

Maturity levels are:

- **Stable:** production-ready and verified.
- **Controlled:** reviewed operational or product documentation.
- **Beta:** usable behind an integration boundary and may require manual action.
- **Planned:** approved direction that is not yet available.
- **Archived:** retained for history and no longer current.
